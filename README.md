# APKs-releases

Публичные APK и описания обновлений. Исходный репозиторий приложений остаётся закрытым; служебный контекст, ключи и пользовательские данные здесь не публикуются.

## VK Видео TV

Экспериментальная независимая оболочка GeckoView + uBlock Origin, не связанная с VK. Android 8+; ARM64 и ARMv7. Основная целевая приставка владельца: Android TV9.

Встроенная кнопка «Обновления» проверяет новые версии, скачивает APK и проверяет размер, SHA-256, пакет, версию и подпись установленного приложения. Установка — только через подтверждение Android, без root и без GitHub-токена на устройстве. Автоматической тихой установки нет.

**Не проверено на настоящей приставке:** управление пультом, вход, видео/DRM, удаление видеорекламы и системная установка обновления. Прототип использует debug-подпись; это не production-релиз. Не обещаем просмотр без рекламы.

Релизы содержат APK, SHA256SUMS, уведомления/лицензии и отдельные исходные материалы открытых компонентов. Собственная независимая оболочка: MIT; uBlock Origin: GPL-3.0; GeckoView: MPL-2.0; AndroidX Core: Apache-2.0. Лицензии компонентов не изменялись.

Полный исходный код нативного движка Mozilla159.0.1, соответствующего BuildConfig используемого GeckoView, доступен отдельно (Maven source JAR содержит только Java-часть):
```
https://archive.mozilla.org/pub/firefox/releases/159.0.1/source/firefox-159.0.1.source.tar.xz
```

У каждого приложения отдельный канал метаданных; выпуск другого приложения не заменяет VK Видео TV:
```
https://raw.githubusercontent.com/Serjoga7831/APKs-releases/main/vk-video-tv/update.json
```
